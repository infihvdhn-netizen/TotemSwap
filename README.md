# TotemSwap

Клиентский Fabric-мод для Minecraft 1.21.11. Нажмите `R`, чтобы переместить первый найденный тотем из основного инвентаря или хотбара в левую руку.

## Настройка задержки

После первого запуска откройте `.minecraft/config/totemswap.json` и укажите `delaySeconds` от `0` до `2`:

```json
{
  "delaySeconds": 0.5
}
```

Задержка задаёт время ожидания после нажатия `R` перед свапом. `0` выполняет свап сразу. Перезапустите игру после изменения файла.

Клавишу можно изменить в меню `Настройки -> Управление -> Назначение клавиш -> TotemSwap`.

## Сборка

Нужны Java 21 или новее и Fabric Loader для Minecraft 1.21.11.

```sh
./gradlew build
```

Готовый JAR появится в `build/libs/`. Скопируйте его в папку `.minecraft/mods` вместе с Fabric API.

## Зависимости

- Minecraft 1.21.11
- Fabric Loader 0.20.1+
- Fabric API 0.141.6
